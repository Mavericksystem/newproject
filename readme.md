# Temporal Multi-Agent Knowledge & Intelligence Platform

We are building a **local-first AI backend platform** that can ingest a large, continuously changing knowledge corpus, understand how information evolves over time, retrieve evidence, and coordinate multiple specialized AI agents to perform research and controlled actions.

### How

* Ingest and version large-scale **Wikimedia data**
* Build **temporal + hybrid retrieval** across text, metadata, vectors, links, and revisions
* Maintain **versioned memory, provenance, and change history**
* Run specialized agents through a shared **agent harness**
* Connect agents to controlled tools/APIs with permissions and audit trails
* Run open-source models locally through **llama.cpp**
* Expose the system through a polished **localhost web UI**
* Measure retrieval, temporal reasoning, agent execution, latency, and resource usage

### What We Showcase

The project demonstrates production-oriented skills across **AI engineering, RAG, temporal knowledge systems, agent orchestration, data engineering, distributed/backend systems, search infrastructure, observability, security, evaluation, and systems programming**.

The goal is not to build another chatbot, but to demonstrate how an **AI system can reason over changing knowledge, preserve evidence, coordinate agents, and safely execute work**.
